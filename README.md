## About Me

Hi, I'm Alexandre Bonnamain.

I've been working in IT for over 20 years, mainly with computer networks and UNIX/Linux systems.

My background includes routing, BGP, switching, VLANs, DNS, firewalls, VPNs, and network troubleshooting. I've also spent many years working with GNU/Linux, particularly RHEL and compatible distributions. FreeBSD is another operating system I'm interested in working with and exploring further.

Linux system administration and networking are the areas I know best. I've always preferred understanding what happens behind a configuration rather than just making something work.

I like working with systems, investigating problems, testing different approaches, and understanding why a particular solution works — or why it doesn't.

Security is part of that work. My interests are mainly in defensive security, especially system hardening, access control, auditing, logging, and protecting Linux and network infrastructure.

I also use Bash and Python for system administration, troubleshooting, and automation.

## About This Lab

This GitHub is my personal technical lab.

It's where I keep configurations, scripts, technical notes, and experiments involving Linux, FreeBSD, networking, and information security.

Much of what I publish comes from technologies I've worked with for years. Some projects revisit familiar subjects in more detail, while others involve new tools, different approaches, or areas I'm investigating.

I want to keep a record of how things were built, why I chose a particular configuration, what I tested, and what the results showed.

That includes mistakes, unexpected behavior, and configurations I had to change along the way.

I'm not trying to build a collection of tutorials or reproduce documentation that already exists. I want this GitHub to reflect the way I work with technology.

Bash, Python, administrative scripts, configuration management, and infrastructure automation.

## Technical Documentation

I prefer to document what I've actually done.

Whenever possible, I include the environment, commands, configurations, tests, and evidence collected during each experiment.

I keep planned work separate from what has been implemented and verified.

I use AI to assist with technical research and documentation review. The configurations, tests, conclusions, and responsibility for what I publish remain mine.
